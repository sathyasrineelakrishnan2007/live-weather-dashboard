
# Live Weather Dashboard with Fetch API

## Project Overview
A responsive weather dashboard that displays real-time weather information and a five-day forecast for a searched city.

## Key Features
- Search weather by city name
- Display current temperature and weather conditions
- Show humidity, feels-like temperature, and wind speed
- Display a five-day weather forecast
- Weather icons based on weather conditions
- Input validation and error handling
- Responsive design for mobile and desktop

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo Weather API

## How to Run
1. Create the four project files.
2. Add the provided code to each file.
3. Open `index.html` in a browser.
4. Enter a city name and click Search.
5. Make sure you have an internet connection.

## API Used
Open-Meteo:
https://open-meteo.com/

No API key is required.

## Expected Outcome
Understand asynchronous JavaScript, fetch and async/await, API integration, dynamic DOM manipulation, input validation, and error handling.
